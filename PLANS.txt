==============================================================================
 LAPIS GAME ENGINE - MASTER PLAN & CHECKLIST
==============================================================================

Goal
----
A from-scratch, Unreal-style 3D game engine written in modern C++ (C++17),
rendering through OpenGL 4.5 core profile. The engine is a static library
("LapisEngine") that games link against; "Sandbox" is the first game built
on top of it.

Design rules
------------
  * Zero third-party dependencies. Windowing (Win32), the OpenGL function
    loader, math, image/model loading are all written in this repository, so
    the project builds with nothing but CMake + a C++17 compiler.
  * Clean module boundaries:  Core -> Math -> Platform -> Renderer -> Scene
    -> Physics -> Assets -> Runtime (Application). Higher layers depend on
    lower ones, never the other way round.
  * Renderer talks to the GPU only through the RHI layer (Renderer/GL*), so a
    DirectX 11/12 backend can be added later without touching game code.
  * Everything that can be tested without a GPU has unit tests. Rendering is
    tested headlessly through an EGL backend on Linux (Mesa llvmpipe).

Target platforms
----------------
  * Windows 10/11 (primary): Win32 window + WGL OpenGL 4.5 core context.
  * Linux (headless): EGL surfaceless context, used for CI and render tests.
